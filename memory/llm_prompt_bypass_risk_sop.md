# LLM 提示词绕过风险说明 SOP

## 适用场景
- 论坛帖子、讨论串、经验贴中出现“怎么破限/怎么绕过拒绝/怎么让模型输出违规内容”
- 需要归档讨论价值，但不能沉淀为可执行模板
- 需要把零散对话整理成风险识别与替代方案

---

## 标准步骤
1. **提取主题**: 识别帖子是在讨论配置替换、agents.md/system prompt 替换、角色扮演规避，还是权限放大
2. **剥离噪音**: 去掉灌水、楼层引用、图片/base64、重复回复，只保留有信息量的风险模式
3. **总结风险模式**: 例如替换系统提示词、伪造合规语境、诱导降级审查、借论坛经验复用模板
4. **提供替代做法**: 对应给出合规路径，如明确任务授权、拆分需求、限定输出范围、增加验证与人工审批
5. **沉淀为风险说明**: 用“常见绕过模式 / 风险 / 合规替代 / 处置建议”四段结构保存

---

## 坑点
- 论坛讨论往往夹杂玩笑和误导，禁止直接当最佳实践
- 不要保留可复制的完整绕过话术或模板名录
- 若帖子里夹带具体违法用途，应只保留风险标签，不保留细节
- 归档目标是提升识别与防御，不是提高复现成功率
