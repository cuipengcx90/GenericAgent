# CTF Skills 集成 SOP

## 适用场景
- 需要把 CTF Skills 类知识库接入 AI Agent
- 需要先做安全审计，再做本地部署与烟雾测试
- 需要按题型给 Agent 提供最小可用技能索引

---

## 标准步骤
1. **先审计来源**: 核对仓库来源、许可证、最近提交、依赖清单；禁止未审计直接接入
2. **做最小安装**: 独立目录 clone，建立虚拟环境，只安装必需依赖，记录失败项
3. **跑烟雾测试**: 仅验证 CLI/索引/最小查询能力；禁止一上来全量跑题库
4. **按题型建索引**: web/crypto/pwn/reverse/forensics/osint/malware/misc/ai-ml 分组，保留入口、依赖、典型关键词
5. **渐进式披露**: 默认只暴露题型与关键词；需要时再展开到具体技巧或脚本路径
6. **接入 Agent**: 先接只读检索，再接工作流调用；保留回退方案
7. **验证输出**: 用 2-3 个真实查询确认命中率、路径可达性、依赖可执行性

---

## 坑点
- 禁止未审计仓库直接进入主工作流
- 禁止把 payload/exp/攻击脚本默认全量暴露给所有任务
- 大仓库先做题型索引，禁止一次性全读进上下文
- 依赖如 `pwntools`、`z3-solver`、`volatility3` 需单独验证，失败要记录到索引
- 产出优先保留“入口/依赖/关键词/适用题型”，不要把长篇资料原样塞进 SOP
