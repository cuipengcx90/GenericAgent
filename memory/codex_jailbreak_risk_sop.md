# Codex Jailbreak 风险说明 SOP

## 适用场景
- 识别“破限/Jailbreak/解除限制/无视策略”类资料
- 处理含高权限配置、策略绕过、提示词规避的文档整理请求
- 需要把危险资料转成可归档、不可直接复用的风险说明

---

## 标准步骤
1. **先识别信号**: 关注“破限、绕过限制、禁用审查、强制执行、高危权限默认开启”等关键词
2. **拆成三类**: 配置类、提示词类、运行方式类；分别记录风险点，不保留原始可执行话术
3. **保留必要事实**: 仅记录涉及的模型、工具、权限模式、上下文窗口、存储策略等环境信息
4. **删除复用路径**: 不保留可直接复制的绕过提示词、规避策略、批量脚本或组合步骤
5. **给出替代做法**: 用正式 SOP 替代，例如角色约束、验证流程、最小权限、人工审批
6. **落盘为风险说明**: 产出“识别信号 / 风险 / 允许替代方案 / 处置流程”四段结构

---

## 坑点
- 不要把“整理文档”误做成“提炼攻击模板”
- 高危配置如 `danger-full-access`、禁审批等，只能作为风险项描述，不能作为推荐默认值
- 提示词规避文本不能进入 SOP 正文或索引摘要
- 若文档同时含少量有用环境配置，应与风险部分拆开记录，避免污染常规 SOP
