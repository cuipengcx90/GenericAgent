# UUYC (网易UU远程) CLI 操作 SOP
> 来源: Sophub 6a69733cfc63276981bdf609 | 作者: kevanchen | 工具: uuyc-cli
> 默认安装路径(Win): C:\Program Files\Netease\GameViewer\bin
> CLI下载: https://a56.gdl.netease.com/uuyc-cli.zip

## 前置条件
- 主程序必须运行(除`version`外几乎所有命令都依赖主程序,未运行→退出码2)
- 需已登录UU远程账号

## 快速开始
```bash
uuyc-cli echo                    # 测试通信
uuyc-cli device list             # 查设备列表(JSON)→记deviceId
uuyc-cli device connect <ID>     # 发起远程连接(填设备ID,如aeawkilohaaac7fx)
uuyc-cli device disconnect       # 断开所有连接(带ID断单个)
```

## 命令全集(要点)
- `version` / `echo [msg]` / `help [cmd]`
- `user info` / `user wallet`
- `device list|connect <id>|disconnect [id]|status`
- `cloudpc list|launch <id>|shutdown [id]|connect <id>|disconnect [id]`
- `term <设备名>` 或 `term --device-id <id>`: 远程终端,仅支持Windows设备
  - `--shell powershell|cmd|zsh|bash` `--list-sessions` `--new-session` `--session-id <id>` `--kill-session <id>`
- `assist`: 远程协助,仅支持macOS设备。`id/reset-code/set-code/allow`不要求登录,`start <对方ID> [验证码]`需要登录

## 退出码
0成功 1配置文件错误 2主程序未运行 3无效命令 4数据不可用 5超时 6终端命令执行失败 99未知错误

## 坑点
- `device connect`只接受设备ID; `term`默认接受设备名,也可用`--device-id`指定ID(两者不同)
- `disconnect`/`shutdown`不带ID → 作用于全部设备,谨慎使用
- 码率`-b`设置下次连接才生效
- JSON输出含`data/success/timestamp`字段,便于脚本解析

## Python调用示例
```python
import subprocess, json
UUYC_BIN = r"C:\Program Files\Netease\GameViewer\bin\uuyc-cli.exe"
def run_uuyc(*args):
    r = subprocess.run([UUYC_BIN, *args], capture_output=True, text=True)
    if r.returncode != 0:
        raise RuntimeError(f"UUYC CLI 失败(exit={r.returncode}): {r.stderr}")
    return json.loads(r.stdout)
```

坑点：raw端点`GET /sophub/raw/{id}`匿名可访问(无需api_key鉴权即可curl拿到原文markdown)。
