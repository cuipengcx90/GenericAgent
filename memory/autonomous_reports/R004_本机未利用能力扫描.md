## 二、高价值未利用能力（≥3个，按ROI排序）

### 🔴 P1 — `keyring`（Python已装）× `keychain.py`（已有工具无SOP）
- **能力**：系统级密钥安全存储/读取（macOS Keychain原生集成）
- **现状**：R3已发现 `keychain.py` 存在但无SOP，Agent存取API key方式不统一
- **扩展设想**：统一所有API token存储入系统Keychain；补充 `keychain_sop.md` 规范调用方式；替代硬编码/环境变量分散存储
- **接入成本**：极低（`keyring` 已装，`keychain.py` 已实现基础封装）

### 🔴 P2 — `watchdog`（Python已装）
- **能力**：跨平台文件系统事件监控（新建/修改/删除实时触发）
- **现状**：`reflect_scripts/05_folder_watcher.py` 已用但是沉默失效脚本（R2结论）
- **扩展设想**：
  1. **监控 `model_responses/`**：新对话写入时自动触发摘要提炼，无需定时轮询
  2. **监控 `sche_tasks/done/`**：新产出文件时自动发飞书通知
  3. **监控下载目录**：新文件到达时分类/重命名
- **接入成本**：极低（代码模板已有，只需启动进程）

### 🟡 P3 — `gh`（brew已装，GitHub CLI）
- **能力**：命令行直接操作GitHub（PR/Issue/repo/release），无需浏览器
- **现状**：`github_contribution_sop` 依赖浏览器操作，未使用 `gh`
- **扩展设想**：
  - `gh issue list` / `gh pr create` 替代手动网页操作
  - 自主任务可直接 `gh repo clone` + `gh pr create` 完成贡献闭环
  - 结合 `gh search repos` 实现 GitHub 冷门工具搜索（TODO第7条）
- **接入成本**：低（需 `gh auth login` 确认token状态）

### 🟡 P4 — `fastapi` + `uvicorn`（Python已装）
- **能力**：毫秒级启动REST API服务
- **现状**：Agent完全无对外接口，只能通过日志/文件观测状态
- **扩展设想**：
  - `/status` 端点：当前任务/上次运行时间/健康状态
  - `/trigger` 端点：外部（手机/飞书机器人）触发指定任务
  - `/report` 端点：实时返回最新autonomous_report
- **接入成本**：中（需设计API + 安全鉴权）

### 🟡 P5 — `moviepy` + `ffmpeg`（Python+brew双重已装）
- **能力**：视频剪辑/转码/截帧/合成字幕，完整视频处理链
- **现状**：GenericAgent完全未涉及多媒体处理
- **扩展设想**：
  - 自动截取会议录屏关键帧 + OCR → 生成文字摘要
  - 批量压缩/转码本地视频节省存储
  - 配合 `adb_ui.py` 处理手机录屏
- **接入成本**：中（需明确使用场景，能力本身零配置）

### 🟢 P6 — `openpyxl`（Python已装）
- **能力**：读写Excel（.xlsx），支持格式/图表/公式
- **现状**：所有自主任务报告均为.md格式
- **扩展设想**：LLM成本分析报告（TODO第5条）输出为Excel，支持用户直接筛选/透视
- **接入成本**：极低

### 🟢 P7 — `apscheduler`（Python已装）
- **能力**：支持cron/interval/date三种模式，持久化存储任务状态，支持动态增删任务
- **现状**：GenericAgent自研 `reflect/scheduler.py`（简单JSON轮询），已有格式解析bug（every_1h问题）
- **扩展设想**：长期可考虑用APScheduler替代自研scheduler，解决格式解析问题
- **接入成本**：高（需重构scheduler，短期不建议）

## 三、汇总表

| 能力 | 接入成本 | 潜在价值 | 推荐优先级 |
|------|----------|----------|-----------|
| `keyring` + keychain_sop | 极低 | 解决P1安全盲区 | 🔴 立即 |
| `watchdog` 激活文件监控 | 极低 | 减少轮询/实时响应 | 🔴 本周 |
| `gh` CLI集成 | 低 | 简化GitHub操作链路 | 🟡 本月 |
| `fastapi` Agent接口 | 中 | 外部可控性 | 🟡 本月 |
| `moviepy`+`ffmpeg` 多媒体 | 中 | 开拓新场景 | 🟢 有需求时 |
| `openpyxl` 结构化报告 | 极低 | 提升报告可读性 | 🟢 随手可用 |
