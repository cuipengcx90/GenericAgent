## 7 局限与残余风险

1. **VAD 不能当语音判据**：2 个反例（`IMG_3467 2.MOV` VAD=1.000 但 0 字；`IMG_3321.MOV` 0.541 但 0 字）⇒ 省算力可用，判结论不可用。
2. **幻觉污染**：3 条低置信输出（37/7/7 字）必须判不可用；一般规则建议：`conf<0.6` 或「字数/时长 < 0.05 字/s」即人工复核（本例 3 条全部命中该规则）。
3. **whisper 中文输出繁简不定**（同一模型对长录音输出繁体、对短片段输出简体）⇒ 若下游要简体，应统一做一次转换，勿按文件分别假设。
4. **口径不一致（生成器缺陷，未改代码）**：`tools/audio_asset_inventory.py` 写 JSON 的 `unique` 用的是「剔除非媒体前」的 32，写 MD 用的是「剔除后」的 30 —— 两个文件同一概念两个数字。本报告统一为「32 唯一 / 30 音视频唯一件」。**修改工具属改自研代码，未擅动**，留作待批（1 行改动：`unique` 字段改用 `uniq` 过滤后的长度，或改名 `unique_all`/`unique_media`）。
5. **TODO 原始数字不可复现**：「33 个音视频 / 15 个无音轨」与本轮全量重扫不一致（本轮 46/14/32，无音轨按文件 16、按唯一件 4）；已按本轮权威口径覆盖，TODO 旧数字不再引用。
6. **成本结论**：VAD 筛子几乎免费（29.6s vs ASR 1735.5s，1.7%），可用「VAD 低分 → 抽样复核」策略把整批 ASR 成本再压约 1/3，但**不可**直接跳过（反例见 §4）。
7. **未做的事**：不做语音检索/RAG 建库、不做说话人分离（diarization）、不删除/移动任何源文件（全程只读 + 生成副本 wav）；`wav/*.16k.wav`（24 个 + 2 个 calib）在 `temp/` 下，属可再生缓存。
