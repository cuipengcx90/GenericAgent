# R428 待批台账注意力压缩器（第 15 批 C7）

## 1. 要解决的问题（一句话）

台账有 **24 个文件 / 137 条未决**，`view_pending.py --aging` 只能按条平铺输出；
真正消耗注意力的不是「有哪些条目」，而是「我现在被问的是哪一类事、批了会怎样」——
本器把 137 条按**主题**聚成 **10 个决策包**，每包给出：涵盖 ID 列表、一句话决策、
不批后果、以及**一包一句**的最小批准语；同时把「只读 ∧ 可逆」的条目单列成自动执行队列。

R413 的 `tools/pending_triage.py` 已做「机器可判三桶 + 单条批准语」，本器**不重做分桶**，两者互补：
triage 回答「哪条机器能判」，本器回答「这些条目在主题上属于哪一件事」。

## 2. 工具与用法

```
python3 tools/attention_compressor.py --coverage          # 一行覆盖率对账
python3 tools/attention_compressor.py --json <路径>        # 机读全量（meta/packages/items）
python3 tools/attention_compressor.py --md <路径>          # 人读决策包视图
python3 tools/attention_compressor.py --readonly-proof    # 只读自证（跑前跑后台账指纹一致）
python3 tools/attention_compressor.py --selftest          # 14 项（含 10 条负控/正控）
python3 tools/attention_compressor.py --ledger-dir <目录>  # 换语料（默认 temp/pending_decisions）
```

注意：**没有 `--out`**（误用会报 unrecognized arguments），产物路径由 `--json/--md` 显式指定。

## 4. 100% 覆盖率是怎么保证的（不是"看着挺全"）

- 主题映射写在工具内的 `TOPIC_MEMBERS`（**显式枚举**每个台账文件的 ID 区间），
  未命中任何包的条目**不会被静默丢弃**，而是进 `unmatched` 并让覆盖率掉下来 ⇒ 自测 NC1 用一条
  伪造 ID 验证「漏一条必报」（`pending=2 mapped=1 coverage=50.0% unmatched=[...]`）。
- 包数上界 10 也有负控（NC2：给 13 个包必须报错）。
- `pkg_sum_ok` / `queue_violations` / `pkg_missing_fields` / `pkg_empty` 四个自洽位在
  `--coverage` 一行里同时给出，当次全部为 `True/[]/[]/[]`。

## 5. 「只读 ∧ 可逆」判据（两轮自我纠错，值得记住）

初版判据过于乐观，被两个真实反例打回：

1. **R408C**：措辞里写着「只读」，实际动作是**新建一个反射器脚本**（要落盘）⇒ 判据改为
   「目标栏出现可执行写动词（新建/追加/写入/改/替换/迁移）即 `writes_files=True`」，
   并加负控 NC7（只读措辞 + 写动词必须判写文件）。
2. **R405A**：写着弱限定语「不改任何现有行」，实际是**新增一行** ⇒ 加负控 NC8。

最终当次分布：`writes_files=129 / reversible=91 / auto_queue=4`。
队列 4 条全部是 `decision/note` 型（无落盘动作的三选一决策，或纯口径订正记录），
与 R413 的 A 桶 14 条**交集为空**（本次脚本实测 `overlap=[]`）⇒ 两器覆盖的是不同维度，不是替代关系。

## 6. 边界与已知限制（后续会话别误用）

- **主题映射是人工定稿的显式表，不是算法聚类**。新增台账文件后必须补映射，否则覆盖率立刻掉下来
  （这正是本文第 7 节 D2 想接线的维护成本所在）。
- `auto_queue` 的语义**只是**「批准它不需要再确认可逆性」，不等于「可以不经批准直接执行」；
  `decision` 型条目仍需要人拍板（如 C26 买盘、C36 停常驻进程）。
- 本器**不写台账、不发通知、不改目标文件**，也不替用户结论；`--readonly-proof` 可复证。
- 包名/包内成员随台账语料变化，**任何写进报告的数字都应以本报告"生成时间"为快照口径**；
  数字随新台账增长会变。
