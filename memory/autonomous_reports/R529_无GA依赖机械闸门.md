## 3. 判据设计

- **语料面**：`git ls-files` 枚举的生产入口 113 文件 + 依赖闭包 29（含数据文件）= 142 文件；不扫全仓文本。
- **记号分类**：`BRIDGE`（可选桥接）/ `PROD_DEPENDENCY`（硬依赖）/ `COMMENT`（注释提及）；另有 `EXCLUDED`——`GA_` 前缀但属本仓自有运行态旋钮（117 处），标 EXCLUDED 不判洞。
- **双向闸门**：新增未登记引用 ⇒ `rc=1`；已登记引用被删或行号漂移 ⇒ `rc=2 DECLARATION_STALE`。
- **fail-closed**：未知 `GA_*` 名（未登记）一律计洞。
- **SELF_EXEMPT**：豁免面恰为本工具自身与声明面文件，且负控 N14 断言「豁免面不得扩大」。
- **strict 档**：`PROD_DEPENDENCY` 默认 `rc=0`（存量登记），`--strict` 下 `rc=1`。

## 9. 操作教训（沉淀）

1. **push 身份**：主仓 `git push` 默认 ssh-agent 无身份 ⇒ `publickey` 拒绝；须 `GIT_SSH_COMMAND='ssh -i ~/.ssh/id_rsa -o IdentitiesOnly=yes'`。
2. **CLI 形态**：本器子命令为位置参数（`scan` / `selftest` / `proof`），写 `--selftest` 会 unrecognized（同 R521 家族）。
3. **worktree 复跑前置**：新 worktree 首跑必先 `python3 control-plane/l1_map_v0/l1.py build`，否则 coldstart_v0 索引面 fail-closed 报红（RULE 24）。
4. **长任务**：`PYTHON=/opt/anaconda3/bin/python3 bash run_tests.sh` 经 `tools/bg_task.py start --name … --shell` 后台起，单次调用内做有界轮询（15s×19 上限）比多轮空转省轮次；本次实际 etime 约 5.5 分钟。
5. **同批提交纪律**：4 文件为纯插入（1140+/0−），numstat 与预期逐项吻合；`run_tests.sh` 仅含我方 hunk（+10）。
