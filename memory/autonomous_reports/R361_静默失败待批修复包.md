## 1. 结论
1. 这两个任务都不是"崩溃"，是**产物级静默空转**：进程照跑、报告照写"已完成/跳过"，但**没有任何人被告知**，也**没有可看的产物**。
2. 其中 x_ai_intel_daily 的**失败性质**已在今晨 10:45 轮（并行会话 + 其 commit 476ea9c 更新 SOP）被修正为"**可见失败**：外部前置条件缺失（浏览器无已登录 x.com 标签页），脚本抛栈是对的"。
   ⇒ 留给本包的真正缺口是两条：**(a) 没人被告知；(b) 就算前置条件满足，产物也不落地**。
3. 本包按此设计：**①** 让"跳过/降级"变成机器可识别标记 + 让 eia 有持久产物；**②** 用只读守卫把"产物冻结/连续降级"变成 24h 内必达的一条飞书告警。
4. **不改任何生产配置**（enabled/schedule/repeat/max_delay_hours 在脚本内被断言冻结）；"是否停任务/是否补 key" 留给你决策。

## 3. patch ①：prompt 级精修（可独立批准）
- **x_ai**：在"等下次调度即可。"锚点后插入**启动脚本前 10 秒只读前置检查**（`TMWebDriver` 会话探测，即上面实测过的那行）；
  - 输出 `X_TAB_MISSING` ⇒ **不启动脚本**、报告首行写标记 `PRECHECK_SKIP_NO_X_TAB`、写明恢复条件（在已连接浏览器登录 x.com 并保留标签页）、不重试不写别的文件；
  - 输出 `X_TAB_FOUND` ⇒ 走原有流程。
- **eia**：追加两步 —— ①只读 key 检查，缺则报告首行写标记 `DEGRADED_NO_EIA_KEY`（不重试不杜撰）；②脚本跑完把完整 stdout 摘要落盘 `temp/eia_reports/eia_<YYYY-MM-DD>.txt`（**本任务首个持久产物**）。
- **机制与安全**：锚点唯一性断言（count≠1 直接拒绝改写）、json 往返风格保持（x_ai 有尾换行/eia 无，实测 234B→675B、595B→1119B）、不变量冻结断言、diff 全量打印、备份目录、幂等标记。
- **验证证据**：diff 9 行/10 行；二次 `--apply` 报"已存在插入段，跳过"；`--revert --apply` 后三个文件 sha 与改前**逐字节一致**；未涉及任务（trendradar_morning）字节未变。
- **预期效果（预测，未实测）**：x_ai 每轮空转从"完整 agent 会话"降为"一行命令 + 极简报告"；eia 由静默变为"标记 + 有落盘产物"。

## 4. patch ②：守卫注入既有反射脚本（零新增定时）
- **为什么注入**：`reflect_scripts/*.py` 每个都需**专属 launchd**（`agentmain --reflect <path>`）才会跑 ⇒ "新建 08 脚本" 等于**新增一个定时**。而 07 的 `com.cuip.genericagent-l2-gate`（30min、RunAtLoad）已在跑，把守卫挂进它的 `check()` 才是真·零新增定时（沿用 R357 同法）。
- **守卫做什么**：`_freshness_findings()` 只读巡检两条判据 ——
  - 产物型：某任务产物目录最新 `.md` mtime 超阈值（当前 3 天）⇒ 告警；
  - 无产物型：done 报告最近 N 份（当前 2）全含降级标记 ⇒ 告警。
  `_freshness_guard()` 命中则**按指纹 24h 去重**推送一次飞书（照 `l2_watch.py` 范式），**恒返回 None、恒不外抛**（不唤起 Agent、0 LLM 成本、不破坏 07 原逻辑）。
- **真数据命中（证据）**：
  - `x_ai_intel_daily: 产物已冻结 36 天（阈值 3 天，最新 20260817_160400.md）`
  - `eia_weekly: 连续 2 次降级（缺 no EIA_API_KEY）且无持久产物（最新 2026-09-20_1443_eia_weekly.md）`
- **验证证据（36 项断言全绿）**：注入后模块可加载；幂等跳过；`--revert` 后 sha 与原件一致；真数据 2 条命中；首推 1 次、第二次因指纹去重不推；全绿场景零推送；`check()` 仍正常返回 None；**与 R357 的 knowledgeC 钩子共存**（两钩子同时存在、`def check():` 仍只有一个、撤回 R361 后 R357 完好）；真仓库 `07_l2_gate.py` 字节未变、真状态文件未创建。
- **边界**：守卫只**告警**，不做任何自动处置（不禁用任务、不改配置）——与 l2_watch「补证据/重开票据是人的决策」同哲学。

**修后（预期收益，标注为预测）**
