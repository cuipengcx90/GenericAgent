- 工具：`tools/sleep_source_crosscheck.py`（新建，只读，纯 stdlib，selftest 7/7）

## 一、结论（先给答案）

1. **两个时间衰减源（knowledgeC 熄屏、pmset 睡眠窗口）现在可以逐日并排比较了**，且本器 kc 侧总量与既有权威口径（`memory/kc_profile/profile.py` 的 `dark_total_hours`）**逐位吻合**：
   `--expect-kc-off-total 249.35` → `[CALIB-OK] kc 熄屏合计 249.350h`（rc=0）。这证明本器没有悄悄改口径（profile.py 只认 `isBacklit` 且 `v=0` 为熄屏，本器同）。
2. **同一时点、同一快照内，kc 熄屏恒大于 pmset 睡眠**（5/5 天），但**差值无稳定比例**（+0.67 ~ +7.49h）。
   ⇒ 两者**不可互相换算**，只能作方向性上界/下界（kc 熄屏=屏幕关闭时长上界；pmset 睡眠=系统真实入睡下界）。
3. **订正一条旧记忆**：L2 里「09-19 17.02h vs 8.01h、09-20 1.71h vs 9.04h = 方向相反」**在当前口径下不可复现**（详见 §四）。
4. pmset 侧数字与 R420 **逐位复现**（657 窗口 / 135118s / 651 darkwake），说明本器对 R420 解析器产物的消费是无损的。

## 二、口径（本器固定，不许漂移）

| 维度 | kc 侧 | pmset 侧 |
|---|---|---|
| 来源 | `ZOBJECT.ZSTREAMNAME='/display/isBacklit'` | R420 `events.json` 的 `windows[]` |
| 判据 | `ZVALUEINTEGER==0` 的时长 = 熄屏 | `wake−sleep` 秒数 = 睡眠窗口 |
| 忽略 | `v=1`（亮屏）不计；无状态行（gap）**不算熄屏也不算亮屏** | DarkWake 不计入睡眠；**未完窗口（`wake=None`）跳过并计数** |
| 切分 | 跨午夜按**本地日**切分 | 同 |

- 「gap 不折算」沿用 `profile.py` §7 的既有结论（gap 内前台事件密度与亮屏段同量级）。
- 「未完窗口跳过」是本器新增的口径：R420 产物尾部的睡眠窗口可能还没等到 wake（实测 1 个），此时既不能算 0 也不能算满，故跳过并在表头报数（`未完窗口 1（跳过）`）。

## 三、实测数据

### 3.1 校准闸门（本器 vs 既有权威口径）

```
$ python3 tools/sleep_source_crosscheck.py --kc temp/kc_live_crosscheck/knowledgeC.db --expect-kc-off-total 249.35
[CALIB-OK] kc 熄屏合计 249.350h == 期望 249.350h（±0.05h）        rc=0

$ python3 tools/sleep_source_crosscheck.py --kc temp/kc_snapshots/2026-09-25/knowledgeC.db --expect-kc-off-total 262.74
[CALIB-OK] kc 熄屏合计 262.733h == 期望 262.740h（±0.05h）        rc=0

$ ... --expect-kc-off-total 999          # 负控
[CALIB-FAIL] kc 熄屏合计 249.350h ≠ 期望 999.000h（口径漂移）     rc=2
```

- live 期望值 249.35 由 `memory/kc_profile/profile.py` 在同库上实跑得出（`dark 249.35h / lit 420.04h / nobj 17417`）。
- 快照期望值 262.74 为 profile.py 在 09-25 快照上的 `dark_total_hours`。
- 两处差值都在 ±0.05h 内，且 0.05h 容差只为吸收 profile.py 的两位小数输出（0.05h = 180s）。
- **负控证明闸门不是摆设**：故意传错期望立刻 FAIL 且 rc=2（本器从 `main()` 返回码生效，`sys.exit(main() or 0)`）。

### 3.2 逐日对账（live 副本 × pmset 09-26 快照；共 5 个共同日，全部 OK）

| 日期 | kc 熄屏 h | pmset 睡眠 h | 差(kc−pmset) | pmset 窗口数 |
|---|---|---|---|---|
| 2026-09-19 | 9.017 | 8.013 | **+1.004** | 35 |
| 2026-09-20 | 9.711 | 9.044 | **+0.667** | 37 |
| 2026-09-22 | 7.932 | 2.155 | **+5.777** | 88 |
| 2026-09-23 | 13.302 | 9.418 | **+3.884** | 299 |
| 2026-09-24 | 16.392 | 8.902 | **+7.490** | 197 |

- 方向：**5/5 `kc>pmset`**；差值跨度 0.667~7.490h（≈11 倍），**没有可用的比例系数**。
- pmset 只在这 5 天有睡眠窗口；其余 24 天 kc 有数据而 pmset 无 ⇒ 本器输出 `NO_DATA(缺 pmset)` 并**保留已有一侧的数值**（不写 0）。
- pmset 侧自校：657 窗口 / 135118s（=37.533h），与逐日和 37.53h 相差 10s，属逐日按 0.001h 舍入的累计误差（每日最多 3.6s）。

### 3.3 快照 vs live（为什么必须固定快照时点）

同一批日期用 09-25 快照的 kc 复算，与 live 副本只有 4 个日期不同：

| 日期 | live kc 熄屏 h | 09-25 快照 kc 熄屏 h |
|---|---|---|
| 2026-08-28 | （窗口外，无数据） | 12.159 |
| 2026-08-29 | 15.264 | 18.393 |
| 2026-09-25 | 14.629 | 13.862 |
| 2026-09-26 | 1.138 | （快照当日尚不存在） |

总量：live **249.350h** vs 09-25 快照 **262.733h**。
⇒ kc 侧**同一日期在不同时点取值不同**（迟写回填 + ~4 周滚动删除），任何比值/结论都必须绑定「哪一份快照、哪一天采的」，否则不可比。本器把这条写进了内置的「允许/禁止」清单。

## 四、订正：L2 旧记的「方向相反」不可复现

L2 原文（R420 条目内）：`跨源禁互推:kc熄屏 vs pmset睡眠 09-19 17.02h vs 8.01h、09-20 1.71h vs 9.04h=方向相反`。

本次用**三种口径**在同一 live 副本上重算这两天（脚本内直接聚合）：

| 口径 | 09-19 | 09-20 | 全期合计 |
|---|---|---|---|
| A：`v=0` 时长（=profile.py 口径，本器采用） | 9.02h | 9.71h | 249.35h |
| B：`v=0` 时长 + gap 折算为熄屏 | 23.97h | 24.00h | 487.85h |
| C：非 `v=1` 时长 | 9.02h | 9.71h | 249.35h |

三种结果**都**对不上 (17.02, 1.71)；且 A/C 相同说明本机 `isBacklit` 只有 0/1 两种取值（1664 行）。
⇒ 旧值不是口径 A/B/C 中任何一种在**当前这份**库上的产物，最可能的解释是**当时读的是另一个时点的 kc 数据**（当时 R420 是 ad-hoc 探针、未留脚本），叠加 kc 已知的迟写回填（L2 自己记过：同日 09-22 随快照 0.90→5.84→11.78h）。

**建议改写**：把 L2 该句的「方向相反」删去，改为
「同一时点同快照内实测 5/5 天 kc>pmset（差 +0.67~+7.49h，无稳定比例）；跨时点/跨口径的历史值不可并列比较（kc 迟写回填+滚动删除）」。

## 五、本器内置的「允许 / 禁止」推断清单（工具输出即带）

| 判定 | 断言 | 理由 |
|---|---|---|
| 允许 | 同一**快照时点**内比较 kc 熄屏小时与 pmset 睡眠小时 | 两者都随快照变动；固定时点后才有意义 |
| 允许 | pmset 睡眠=「系统真实入睡」下界、kc 熄屏=「屏幕关闭」上界 | 实测同一时点 5/5 天 kc>pmset（+0.67~+7.49h）⇒ 可作方向性上界，不可作换算 |
| 禁止 | 由 kc 熄屏推断 pmset 睡眠（或反向） | 同一时点 5 天 kc 恒大于 pmset 但差值无稳定比例；旧记「方向相反」的值不可复现 ⇒ 属跨源外推 |
| 禁止 | 跨快照时点比较 kc 侧数值 | 迟写回填 + 滚动删除（窗口在动） |
| 禁止 | 把 kc gap 算作亮屏或熄屏 | profile.py §7：gap 内前台事件密度与亮屏段同量级 |
| 禁止 | 把 pmset darkwake 计作睡眠 | DarkWake 是短暂唤醒，不构成睡眠窗口 |
| 禁止 | 缺数据日写成 0 | 0 与「无睡眠」不可区分 ⇒ 输出 NO_DATA |
