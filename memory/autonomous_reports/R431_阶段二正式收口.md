## 5. 本次踩到的三个坑（给下一个人）

1. **`l1_map` 输入变了 ⇒ 必须重建 + stamp**：`control-plane/l1_map_v0/index.json` 含 `built_at` 字段，改了受守输入而不 stamp，`derive_guard check` 会报 STALE/TAMPER（看着像产物被手改）。改 `docs/**` 里被 l1_map 收集的文件属此类。
2. **`AGENTS.md` 不在 derive_guard 输入集**：改它不需要 stamp（本次实测 `check` 仍 OK=4 MANUAL=2 rc=0）；但它是「收用例规则」的契约面，新增仓级门禁类用例要同步改它（本次把两条→三条）。
3. **GA 仓提交必须防误带他会话改动**：`memory/global_mem_insight.txt` 同一文件里同时有本会话与他会话未提交改动时，**不能** `git add` 整文件。做法 = `git show HEAD:<file>` 作基座 → 只替换自己那一处（assert count==1）→ `hash-object -w` → `update-index --cacheinfo` → `git commit`（**不带 pathspec**，否则取工作区内容覆盖刚设的 blob）。收尾判据 = `git diff --numstat -- memory/` 只剩他会话的新增行（本次实测 1/0）。
