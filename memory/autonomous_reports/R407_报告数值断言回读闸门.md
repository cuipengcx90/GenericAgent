## 2. 设计（六条强制条件的落点）

**检查①：冻结证据一致性 / 内部一致性**（条件①）
抽「可复算键」claim：键 ∈ {行数/lines、字节/bytes/size、sha1/sha256/md5/哈希、条/项/count、B/KB/MB/GiB 等尺寸}，同一 (主体, 键) 出现多个**不等价**值即报警。
- 同一句两处一在**代码块**内、一在正文 ⇒ `FROZEN`（一处在粘贴的原始输出，一处是转述 ⇒ 后者更可能是手抄漂移）
- 两处都在正文 ⇒ `INTERNAL`

**检查②：比例自洽**（条件①）
`a/b` 与紧邻百分比互算：`29/32 = 90%`（后置）与 `99 / 341（12.0%）`（前置）两种写法都认；偏差 > 3 个百分点才报，容差随显示精度收紧（整数百分比 +0.5）。

**检查③：现场复算**（条件①，仅静止可复算类）
仅当 claim 主体能解析成**真实存在的文件路径**、且该文件落在 `--frozen` 集内时，现算行数/字节/sha1 比对；文件已不在盘上则跳过（不报缺文件——归档搬迁是常态）。

**检查④：单位换算**（条件⑥）
同键不同单位先换算再比，`1,211,565,564 B` 与 `1211565564B`、`99 / 341` 与 `99/341` 判等价 ⇒ 不刷屏。

**永不自动比对白名单**（条件②，`--list-never` 可打印，机制上先于任何比对生效）
5 类（`NEVER_PATTERNS` 实测 `len=5`）共 2313 处命中被跳过：时间戳/日期 727、外部/网络数据 874、耗时/时变 447、进程/内存/负载 233、增长型计数 32。

**零 shell**（条件④）
全流程只用 `open()` 读 + `os.path.getsize` + `hashlib` 现算，**没有任何 subprocess/管道/重定向**——「命令白名单」是结构性的，不是声明性的。

**只读**（条件⑤）
扫描前后对全部被扫文件做 sha1 比对，`stats["written_detected"]` 非空即 rc=3 + `[FATAL]`。

## 4. 歼灭 22 条假警报：唯一有效的口径

按条件③「真归档只要求 0 假警报」，本轮把**全部精力放在降误报**。迭代中累计 20 余条假警报（最后一轮一次性列出 16 条，其余为先前零星修掉的），**几乎全部同因**：*两个数值共用同一前缀，但根本不是同一个实体*。逐类实录：

| 形态 | 实例 | 错在哪 |
|---|---|---|
| 表格一行多列 | R385 `\| 09-24 10:28 \| 907 MB \| …values \|` vs `\| 09-24 10:28 \| 879 MB \| …stubs \|` | 行首"列"相同，数值属于**不同文件** |
| 代码块不同服务名 | R359 `logs/a.log 372 行` vs `logs/b.log 374 行` | 同段不同 log |
| 原文件/新文件 | R360 原 x.json 与新版 x.json | 是同名不同代 |
| 自证行 | R384 `bytes=53956` vs `bytes=3824` | 是「工具自证」里的两个不同对象 |
| T0 备份清单 | R381:58-65 连续 8 行 `47.2 / 16.0 / 15.0 / 12.5 / 12.5 / 12.5 / 8.5 / 7.4 MiB`，各跟不同路径（含 2 个 `kc_snapshots/*/knowledgeC.db`） | 是**8 个不同备份对象** |
| 模型参数量名 | R360 `[1.5B]` / `[3B]` | 不是尺寸断言，是模型名 |
| 条数/占比缩写 | R396:33 `**与前次快照（R373，n=341，LOW 34/12.5%）对照**` | 分母是百分比不是计数 ⇒ 被读成 `34/12` 算成 283% |

**最终口径（关键一行）**：比对主体 = (段落路径 或 章节标题) + **「上下文本签名」= 把该数值自身遮蔽（替换成 `#`）后的整行归一化文本**。
这一步把上面七类一次性归零：表格两行遮蔽数值后仍差在列尾；不同 zip 名字保留在行内；`[1.5B]` 与 `[3B]` 遮蔽后仍不同。**此前试过的所有"取数字前短标签"方案都必然复发**——短标签天然会在不同实体间撞车。

配套的三条收窄：
1. 裸 `B` 只认 ≥3 位整数（挡 `[1.5B]` 这类模型名）；方括号包裹的 token 一律不抽。
2. 比例式要求 `b` 不是小数、且 `a/b` 与百分比之间的分隔符**不跨** `】|：:，,、`（挡表格栅格与缩写复述）。
3. 比例偏差阈值 3 个百分点（挡整数百分比舍入，如 `29/32` 报 `90%` 而非 `90.62%` 属合理近似）。

> 副作用（明示）：口径收紧后灵敏度下降——同一实体的**异文件**复制件漂移不再报（如"报告 A 说 907MB、报告 B 说 879MB"）。这是条件③"真归档 0 假警报"优先下的**自觉取舍**，不是漏做；若将来要跨文件比对，须另开 `--cross-file` 开关并单独做误报标定。

## 5. 已知边界（不覆盖，勿当已覆盖）

1. **只认它认识的键**：数值若写成纯数字不带键（如"本期 372"），无法判定它指行数还是条数 ⇒ 不比对。
2. **跨报告/跨文件一致性不查**（见上"副作用"）。
3. **STAT 覆盖面**：仅当主体是真实文件路径且该文件在 `--frozen` 集内；且引用**归档当年**的行数会随时间漂移 ⇒ 默认只对 `memory/autonomous_reports/R*.md` 做 frozen，且归档扫描里 STAT 实测 0 条（历史报告引用的行数多已随文件改写过期，这类"历史快照 vs 现值"比较无意义，故不纳入闸门）。
4. **时变值不算**（白名单兜住）：mtime/耗时/内存/负载/外部站点/增长型计数 —— 这类正是 R375 那次"mtime 写错"的事故类型，机器无法复算，只能靠人当场粘贴。
5. **不算"事实正确"**：闸门只判**自洽性**（同报告内两个值是否打架）。数字与外部真值是否一致，仍取决于写报告时是否真的粘贴了原始输出。
