## 8 工具自曝坑与边界

1. **打印路径的键依赖**（本批实测踩到）：审计器首跑已在写 JSON 之后崩于复用分支取 `cmd` 键（KeyError），`seconds` 也是 `None` 被印成 `Nones`。修法：`cl.get('cmd')` 兜底 + `seconds is None` 时打印「复用已有 clone，未计时」。教训：**JSON 落盘在打印之前**，所以「看到 Traceback」不等于「没产出」，判产物要看文件 mtime 而非 stdout。
2. **复验必须传 `--clone-dir` 复用**，否则每跑一次重建 112M 克隆；本批把 clone 留在 `/tmp/ga_clone_r418_verify2` 供复核。
3. **`core.quotepath` 陷阱**（复现 R401 教训）：中文路径默认被加引号转义，按空格/集合比对会造成假失配（本批一次错误统计得到 245 vs 真值 32）。凡按路径集合比对必带 `-c core.quotepath=false`。
4. **抽取器边界**：只识别形如路径的 token，跳过 URL/占位符/散文斜杠（skip 142 条）；**判定只回答「这条路径在本机/克隆里在不在」，不回答「文档本意指哪」**，故 §4 的三桶定性必须人工过一遍。
