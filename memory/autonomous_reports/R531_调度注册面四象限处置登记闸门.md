新增/变更面：

1. **登记面** `memory/schedule_registry/FAMILY_DISPOSITION.json`：`entries: family -> {status, evidence[], note}`；
   `status ∈ {LEGACY, DEFERRED}`（LEGACY 与 R470 判据表 `state=legacy` 同义；DEFERRED=真无人认领、处置待批）。
   `evidence` 格式 `<repo 相对路径> | <token>`，须**文件存在 ∧ token 逐字命中**。
2. **闸门** `guard_disposition`：三违规码 `UNDISPOSED`（④ 家族无登记）/ `CLAIM_WITHOUT_EVIDENCE`（登记证据不可回源、status 非枚举、evidence 为空）/ `DISPOSITION_STALE`（登记家族已消失，或已被四源认领）。
3. **新子命令** `disposition`（位置参数）：= `scan` + 闸门，退出码 `0=无违规 / 1=有违规 / 2=输入无效`（产物面空或四源全空 ⇒ fail-closed rc=2）。
4. **`--ccd-json`**：可选注入 `content_change_detector` 的 `discover-done` JSON，输出**精确**口径差（= 本器分母 − CCD 家族集）；缺文件时记 `ccd_error` 不崩，回落到判据表面代理口径（`NC29`）。
5. **`scan` 输出纯增键**：每条家族加 `disposition`；`counts` 加 `disposed`/`unclaimed`/`coverage`；顶层加 `disposition_path`。

## 6. 口径与边界（务必与相邻器区分）

- **三套分母不可互推**：本器 31 = 全部 done 族；`task_freshness`/判据表 27 = 判据表可见族（∩ 双口径）；`content_change_detector` 26 = `targets ∩ done`。故「口径差 4 / 5」是**集合差**，不是「漏报数」。
- **登记 ≠ 处置完成**：`DEFERRED` 3 条只是把「真无人认领」显式化并留痕，处置（补 legacy 登记 / 明确退役停产物）属政策面，**待批**；本件不代停用。
- **`scan` rc=1 非故障**：仅表示存在 ④ 空洞，需人工判读；`disposition` 的 rc 才是治理闸门。
- **不新增拒绝行为**：本件只加「登记 + 判据」，不改变任何调度面执行路径。
