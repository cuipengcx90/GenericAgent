## 2. 10 月大家怎么用

- **主力模型**：`gpt-6-astra`（走 CC 反代面）+ `gpt-6-astra-cc-format`（codex 面）；claude-opus 4.8 / 5.x 系；10-03 晚新上 `claude-fable-5-1-reversed`（逆向渠道）。
- **长任务长跑是主用法**（假期场景）：「假期真是爽，一直蹬都没断过，一个 goal 跑了快两天了还没断流」（10-02 段）；「依旧爽蹬，一天少不到 60 刀」。
- **强度设定**：日常 high 够用；有楼提到「xhigh 从 5.4 开始，很容易过度思考导致效果更差」。
- **会话/上下文**：路由到 low/high 由「会话窗口」决定 ⇒ 变笨就开新会话；上下文接近 200k 附近会变慢/断流。
- **cc 面 vs codex 面有分歧**：10-03 有人说「Astra 还得是在 codex 里面才好用一点」，10-02 则有人说「在codex里面使用好傻啊」「cc版本的gpt6好用一点」（#22383，同一楼）——即**同模型两面体感不一致**，不是稳定结论。
- 其他：挂自动签到的做法（**有被封案例**）；额度紧张时「留着额度来日再战」。

### B. 常态错误清单与错误解法（#22181，09-30 20:01）

- 空回 / 中断 → **重开窗口 / 发「继续」**
- 524 → 刷新等
- token rate limit（带 ETA）→ 等
- 429 / 503 → 等或换模型
- FAST 模型 → 建议别用
