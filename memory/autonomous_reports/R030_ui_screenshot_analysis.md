## UI模式分类（5类）

### 1. 列表页（List View）— 占比约48%

**特征**：
- 顶部筛选栏：多条件组合查询（日期范围、下拉选择、关键词搜索）
- 数据表格：支持排序、分页、批量操作
- 操作按钮：导出、新增、重置、查询

**代表页面**：
- 供应链分析/实时库存查询：品项编码、品项名称、库存量、可用量、占用量、预计出库量、预计入库量、库存金额
- 供应链分析/采购汇总表：供应商编码、仓库编码、计划采购数量、实际收货数量、实际收货金额

**技术栈线索**：
- 表格组件：支持固定表头、横向滚动（字段数≥10列）
- 筛选栏：日期范围选择器、级联下拉框、多选框
- 导出功能：Excel导出（常见于企业管理系统）

---

### 2. 表单页（Form View）— 占比约21%

**特征**：
- 分组布局：基础信息、扩展信息分区
- 必填标识：红色星号 `*` 标记必填字段
- 输入控件：文本框、下拉选择、日期选择器、数字输入框、富文本编辑器
- 底部操作：取消、确定按钮

**代表页面**：
- 供应链管理/品项主档/新增&编辑：品项编码（系统自动生成）、品项名称、品项类别、品项属性、规格、保质期、存储方式、税率、产地、品牌、所属供应商
- 商品管理/饮品商品模板库：餐品名称、商品分类、热搜词、卖点、商品描述

**技术栈线索**：
- 表单验证：必填校验、格式校验（如品项编码自动生成规则）
- 级联选择：品项类别→品项属性（二级联动）
- 单位换算：体积（cm³）、重量（KG）

---

### 3. 详情页（Detail View）— 占比约13%

**特征**：
- 只读展示：字段值不可编辑
- 分区布局：基础信息、订单商品、操作日志等分区
- 状态标识：订单状态（已发货、退款中）、单据状态
- 返回按钮：左上角返回上级列表

**代表页面**：
- 供应链管理/门店订货单/查看：订货单号、订单时间、门店、订货人、期望到货时间、发货时间、收货人、联系方式
- 订单管理/售后订单管理/订单详情：原订单编号、退款单编号、退款类型、所属门店、订单时间、退款单时间、订单来源、商品数量
- 营销管理/券活动管理/详情：活动名称、活动时间、活动封面图片、活动内容图片、活动规则

**技术栈线索**：
- 时间格式：`YYYY-MM-DD HH:mm:ss`（标准ISO格式）
- 编号规则：`DH20260316000015`（前缀+日期+流水号）、`TD9003214148732767846401`（退款单前缀TD）
- 图片预览：支持封面图、内容图上传展示

---

### 4. 报表页（Report View）— 占比约10%

**特征**：
- 汇总统计：按维度聚合数据（供应商、仓库、品项）
- 多维筛选：时间范围、状态、是否过滤红冲单
- 导出功能：支持Excel导出

**代表页面**：
- 供应链分析/采购汇总表：按供应商、仓库、品项汇总采购数据

**技术栈线索**：
- 聚合计算：计划采购数量、实际收货数量、实际收货金额
- 红冲单过滤：财务逻辑（冲销单据）

---

### 5. 管理页（Management View）— 占比约8%

**特征**：
- 树形结构：左侧导航树 + 右侧内容区
- 批量操作：批量启用/禁用、批量删除
- 权限控制：操作按钮根据权限显示

**代表页面**：
- 门店管理/门店列表/门店实物商品管理
- 主数据管理（推测有组织架构、权限配置等）

## 技术栈推断

### 前端框架
**高概率**：Vue.js 2.x/3.x + Element UI / Ant Design Vue
- **证据1**：表格、表单、日期选择器的视觉风格符合Element UI特征
- **证据2**：筛选栏布局（左对齐标签 + 右侧输入框）是Element UI默认样式
- **证据3**：按钮样式（主按钮蓝色、次按钮白色边框）符合Element UI规范

**备选**：React + Ant Design（可能性30%）

### 后端技术
**推测**：Java Spring Boot / Node.js
- **证据1**：编号规则（前缀+日期+流水号）是Java企业应用常见模式
- **证据2**：红冲单、税率等财务术语暗示有ERP背景，Java在企业级应用中占主导
- **证据3**：系统规模（12大模块、141张UI）需要成熟的企业级框架

### 数据库
**推测**：MySQL / PostgreSQL
- **证据**：订单编号长度（19位数字）符合雪花算法（Snowflake ID），常用于分布式MySQL

### 部署架构
**推测**：前后端分离 + 微服务
- **证据1**：模块划分清晰（供应链、订单、营销独立），符合微服务拆分原则
- **证据2**：系统名称"尚饮点餐管理后台"暗示有C端点餐小程序/App，后台是独立服务

## 可复用组件建议（8个）

### 1. 通用筛选栏组件（FilterBar）
**复用场景**：所有列表页（48%页面）
**功能**：
- 动态配置筛选字段（文本、下拉、日期范围、多选）
- 重置/查询/导出按钮
- 筛选条件持久化（URL参数）

**实现要点**：
```javascript
<FilterBar
  :fields="[
    { type: 'input', label: '品项名称', key: 'itemName' },
    { type: 'select', label: '仓库', key: 'warehouseId', options: warehouseList },
    { type: 'daterange', label: '单据日期', key: 'dateRange' }
  ]"
  @search="handleSearch"
  @export="handleExport"
/>
```

---

### 2. 数据表格组件（DataTable）
**复用场景**：所有列表页、报表页
**功能**：
- 固定表头、横向滚动
- 排序、分页、批量选择
- 自定义列渲染（状态标签、操作按钮）

**实现要点**：
- 支持虚拟滚动（数据量>1000行时性能优化）
- 列宽自适应 + 手动拖拽调整
- 导出Excel时保留筛选条件

---

### 3. 表单构建器（FormBuilder）
**复用场景**：所有新增/编辑页面（21%页面）
**功能**：
- JSON配置驱动表单渲染
- 必填校验、格式校验、异步校验（如品项编码唯一性）
- 级联选择、动态显隐字段

**实现要点**：
```javascript
<FormBuilder
  :schema="{
    itemCode: { label: '品项编码', type: 'input', disabled: true, autoGen: true },
    itemName: { label: '品项名称', type: 'input', required: true },
    category: { label: '品项类别', type: 'cascader', required: true, options: categoryTree }
  }"
  v-model="formData"
/>
```

---

### 4. 详情页布局组件（DetailLayout）
**复用场景**：所有详情页（13%页面）
**功能**：
- 分区展示（基础信息、扩展信息、操作日志）
- 字段标签对齐（左对齐 + 冒号）
- 返回按钮 + 面包屑导航

---

### 5. 编号生成器（CodeGenerator）
**复用场景**：订单、单据、品项编码生成
**规则**：
- 订货单：`DH + YYYYMMDD + 6位流水号`
- 退款单：`TD + 19位雪花ID`
- 品项编码：`WP + 4位流水号`

**实现要点**：
- 后端统一生成（避免并发冲突）
- 前端展示"系统自动生成"提示

---

### 6. 状态标签组件（StatusTag）
**复用场景**：订单状态、单据状态、审批状态
**功能**：
- 颜色映射：待审批（橙色）、已通过（绿色）、已拒绝（红色）、已发货（蓝色）
- 支持自定义状态枚举

---

### 7. 图片上传组件（ImageUploader）
**复用场景**：活动封面、商品图片、资讯配图
**功能**：
- 拖拽上传 + 点击上传
- 图片裁剪（固定比例）
- 压缩上传（前端压缩至<500KB）

---

### 8. 导出Excel组件（ExcelExporter）
**复用场景**：所有列表页、报表页
**功能**：
- 前端导出（数据量<5000行）：使用 `xlsx.js`
- 后端导出（数据量>5000行）：异步任务 + 下载链接
- 导出时保留筛选条件、排序规则

- 按钮：主按钮（蓝色填充）、次按钮（白色边框）

## 与AI工作流v7架构集成建议

### 1. 组件库自动生成
- **输入**：UI截图 + OCR文本
- **输出**：Vue组件代码（.vue文件）
- **工具链**：GA + vision_utils + 代码生成模板

### 2. 表单配置自动推断
- **输入**：新增/编辑页截图
- **输出**：FormBuilder的JSON schema
- **示例**：
```json
{
  "itemCode": { "label": "品项编码", "type": "input", "disabled": true, "autoGen": true },
  "itemName": { "label": "品项名称", "type": "input", "required": true, "maxLength": 50 },
  "category": { "label": "品项类别", "type": "cascader", "required": true }
}
```

### 3. API接口自动生成
- **输入**：列表页筛选条件 + 表格字段
- **输出**：RESTful API定义（OpenAPI 3.0）
- **示例**：
```yaml
/api/supply-chain/items:
  get:
    parameters:
      - name: itemName
        in: query
        schema: { type: string }
      - name: warehouseId
        in: query
        schema: { type: integer }
    responses:
      200:
        content:
          application/json:
            schema:
              type: object
              properties:
                items: { type: array }
                total: { type: integer }
```
