## 6. 与 R411 `task_freshness.py` 的分工边界（写死口径）

| 层 | 判据 | 看得见 | 看不见 |
|---|---|---|---|
| R411 L1 | 产物 mtime 过期 | 任务停跑、产物不再更新 | 产物在更新但**内容零变化** |
| R411 L2 | 日志/证据尾部降级签名 | rc=0 的静默降级 | 同上（日志可能完全不提） |
| R411 L3 | 运行缺席（DISABLED 等） | 任务被归档/停用 | 同上 |
| **本器（内容层）** | 归一化后指纹去重 + 距上次实质变化天数 | **跑而不产出**（心跳） | 任务是否该跑、产物语义是否正确 |

结论：三层与本层**互补非替代**；本器不产出「任务失败」判定，只产出「产出内容停滞」判定，等级命名沿用 R411（ALERT/WARN/OK/INFO/DISABLED）。

## 7. 接线提案（待批，revers=0）

**落点**：`tools/task_freshness.py:236` — 在 `    # ---- L2 静默降级签名 ----` 该行**之前**插入 L1b 段（沙箱原型即此位置，实测通）。

**块内容（沙箱已验证，仅需把硬编码路径去掉）**：

```python
    # ---- L1b 内容级产出变化（补齐 mtime 盲区：跑而不产出） ----
    cont = t.get("content")
    if cont:
        import sys as _sys
        _sys.path.insert(0, os.path.dirname(os.path.abspath(__file__)))
        import content_change_detector as _ccd
        crows = []
        for pat in (cont.get("globs") or []):
            info = _ccd.scan_family(root, pat, cont.get("max_content_stale_days", 7),
                                    cont.get("min_files", 3), cont.get("max_files", 500),
                                    cont.get("hash_cap", 65536), True)
            crows.append(info)
            lim = cont.get("max_content_stale_days", 7)
            if info["class"] in ("ALL_IDENTICAL", "CONTENT_STALE") and (info["stale_days"] or 0) > lim:
                bump("ALERT" if info["class"] == "ALL_IDENTICAL" else "WARN",
                     "L1b 产出内容零变化：%s（n=%d distinct=%d 距上次实质变化 %.2fd）"
                     % (pat, info["n"], info["distinct"], info["stale_days"]))
        res["contents"] = crows
```
