# R557 L站浏览停摆事故：自愈判据被 connect 子域骗过（2026-10-06）

## 0. 用户问题与结论
用户问：「浏览L网站，今天到上限了吗？怎么感觉半小时没再浏览了」

**结论：未到上限**（当日 `state.daily['2026-10-06']=53`，当日 cap=180）。停摆真因是**供应侧标签漂移 + 自愈判据失效**：唯一 linux.do 主站标签被导航到 `connect.linux.do`，而补标签前的「已有 linux.do 标签」判据用子串匹配被 connect 骗过 ⇒ 自愈永不触发，浏览循环每轮空转。

## 2. 根因

### 根因 A（卡死直接因）判据双份且不一致
`tools/linuxdo_browse_daemon.py` 存在两份「是不是 linux.do 主站」的判据：

- 会话选择 `pick_session()`（L303/L335-337）：**精确 host** 且排除 connect ⇒ 恒无候选 ⇒ 每轮直接判 `non-linuxdo-tab`
- 补标签 `try_ensure_tab()`（L1348 附近）：osascript 里写 `if (URL of tb) contains "linux.do"` ⇒ `https://connect.linux.do/` **被判为已有主站标签** ⇒ 自愈分支直接短路

两者矛盾：一边说没有可用标签、另一边说已经有了。后果=**永不补标签、永不恢复**，且日志每轮只报 `non-linuxdo-tab`（看起来像站点/驱动问题，实际是本地判据缺陷）。

### 根因 B（隐患，同类风险的源头）
`check_level()` 按 SOP 顺序先导航到 `https://connect.linux.do/` 读等级卡，读完再导航回主站。若中途抛异常或进程被杀，标签就**永久留在 connect**——正是 A 的触发条件。`level_log.jsonl` 末次 `source=connect` 记录为 `2026-10-06 12:53:07`（当日 27 条），故 21:52 这次漂移的触发者无法从台账归因，但「读 connect 后可能回不来」的缺口是结构性的。

## 3. 物证
- `osascript` 枚举 Chrome **全部窗口标签**：全机仅 2 个标签，其中 `https://linux.do/` 的 URL 已经被改成 `https://connect.linux.do/`
- 桥会话表（`list_sessions()` 只读）：只有 `connect.linux.do` 与 `new.sharedchat.cc`，**无 linux.do 主站**
- 因此「非主站标签」判定正确，缺的是**自愈**。

## 4. 修复（`tools/linuxdo_browse_daemon.py`，落盘 23:16:13）

单一源判据 + 三处行为补丁 + 一处加固：

1. **`MAIN_HOSTS`/`_is_main_host()`/`_url_host()` 单一源**（L98/L109/L111）：host 必须**精确**等于 `linux.do` 或 `www.linux.do`；`connect.linux.do`、`evil-linux.do.attacker.com` 一律否
2. **osascript EXISTS 段改为返回 `URLS:<每行一个URL>`**，Python 侧用 `any(_is_main_host(_url_host(u)) for u in urls)` 判定「已有主站标签」⇒ connect 不再能冒充
3. **`pick_session()` 改用同一函数**（原为等价的字面比较）⇒ 两份判据合一，杜绝再次分叉
4. **批内漂移即中止**：批次中途会话漂到非主站 host 时中止该批（不再连续刷 FAIL）
5. **`check_level()` 加 `try/finally` 还原主站 + 还原后探针校验**，异常路径只告警不吞（治根因 B）

自测：`python3 tools/linuxdo_browse_daemon.py --selftest` ⇒ **35/35 PASS**（改前 33，新增 T7p/T7r/T7s：connect 不得判「已有」、子串后缀不得误判、结构与真跑一致）。

## 7. 教训（已写进 SOP）
1. **同一语义禁止两份判据**：子串匹配（`contains "linux.do"`）会被同族子域（`connect.linux.do`）骗过；host 判定必须精确 + 单一源函数。
2. **「有标签」与「能用」是两回事**：自愈判据必须与消费侧（`pick_session`）用同一个函数，否则会出现「一边说没有、一边说有」的永久空转。
3. **等级检查导航 connect 是已知危险路径**：任何把主站标签导航去别处的分支，都必须 `try/finally` 保证还原，并留下可观测证据。
4. 判停摆是否「到上限」先看 `state.daily` 与当日 cap，不要凭感觉；本次 53/180，是自愈缺口不是限额。
