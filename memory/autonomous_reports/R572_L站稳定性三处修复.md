浏览 / 回帖 / 点赞 / 发帖全走 TMWebDriver 桥(execute_js),不受 AppleEvents 授权影响。## 2. 三处修复(D1/D2/D3)

### D1 抓取韧性:页内 fetch 全失败 ⇒ 换会话重试(旧行为单发即弃)
- 现场:单次页内 fetch 返 `TypeError: Failed to fetch`(前台标签正在导航时常见)⇒ 整批 0 候选 ⇒ 白睡一个批间空档。
- 实现:抽出 `fetch_round(session, pages)` 单一内核(按页保序取候选);采样页**全失败且非强风控** ⇒ 短随机延迟后换会话重试;`raise RiskAbort` 分支位置在 T19 结构断言里锁死(强风控仍零帖中止,不得被重试路径绕过)。

### D2 零产出归因分列:抓取全失败 ≠ 候选全重
- 新增纯函数 `zero_yield_kind(stats)`:`pages>0 且 ok==0` ⇒ `FETCH_FAIL`;其余(含 pages==0)⇒ `ALL_SEEN`。
- 价值:日志/回执可区分「抓取链路坏了」与「正常但今天没新帖」——否则两者都是「0 候选」,与 R467「artifact 层对跑而不产出无力」同源。

### D3 -1743 非 AppleScript 兜底:桥 `window.open` 建后台主站标签
- 常量 `BRIDGE_OPEN_JS`:任一会话内 `window.open('https://linux.do/','_blank')`。
- helper `_try_bridge_open_main_tab()`:遍历 `list_sessions()`,逐个 `run_js(id, BRIDGE_OPEN_JS, timeout=15)`;
  成功判据 = **3s 后 `list_sessions()` 内出现主站会话**(`_is_main_host(_url_host(url))`,与 picker 同一判据源),否则 fail-closed 返回 False + 逐因 note。
- 接线:try_ensure_tab 中 osascript 路径失败(-1743)时改走该兜底,台账 note 以 `BRIDGE_OPEN` 前缀可辨识。
- 实测(2026-10-11,只读探测):
