## 3. 本次新发现（文档漂移与缺口）

### D1 ★ L3 的「三件套」子集已落地并**已在 CI**，ROOT_MAP 状态陈述已过期（且把两件事混为一谈）
> **本节为勘误后的结论**（初稿误判成「已实现未接线」，根因＝用 `grep -n 'l3' run_tests.sh` 判接线：
> 该脚本用的是 **glob 自动发现** `for d in control-plane/*/`（见 run_tests.sh:100），字面量 grep 必零命中 ⇒ 假阴性。
> 订正方法：独立复现发现逻辑，实测 14 个 control-plane 套件里有 `control-plane/l3_skills_v0/`（tests=2）。）

- **实际状态（实测）**：
  - `control-plane/l3_skills_v0/` 有 `check_skills.py`（技能三件套检查器：SKILL.md front-matter 的 `version` /
    `FAILURE_MODES.md` ≥3 条 / `evals/` 非空，fail-closed）+ `test_check_skills.py` + `test_handoff_slots.py`。
  - `python3 control-plane/l3_skills_v0/check_skills.py` → `skills=3 ok=3 fail=0` rc=0
    （autopilot version=0.5.1 / herdr-handoff version=0.6.0 / herdr-team version=0.5.1）。
  - `python3 -m pytest control-plane/l3_skills_v0 -q` → `26 passed in 0.02s`；run_tests.sh 自动纳入。
- **真实缺口（唯一）＝文档状态陈述过期**：`ROOT_MAP.md` 有 4 处仍写「L3 仍未做」（L26 / §2 表 L63 / L65 / §11-3 L156），
  并把「三件套」与「L3 能力地图主体」混写在同一个 ⬜ 里 ⇒ 读文档的人会以为三件套也没做。
- **两件事必须拆开**（据 `FUTURE_CAPABILITIES.md` §8 的定义）：
  - **三件套**：✅ 已落地、已进 CI（上一条实测）。
  - **L3 能力地图主体**（每条资产 = `{skill, version, eval_ref, failure_modes[], cost_profile, evidence}`，manifest 加 `capability:` 段）：
    ⬜ 未做，且**触发条件是题集 ≥15 题**（当前 acceptance_v1 = 7 题）⇒ 现在不该做，但文档该写清。
- **建议（零新组件，小时级）**：把 ROOT_MAP 四处状态陈述改成
  「三件套 ✅ 已落地并进 CI（`control-plane/l3_skills_v0`，26 用例）；L3 主体 ⬜ 未做（触发条件=题集 ≥15 题，当前 7 题）」。
  `run_tests.sh` **无需改动**（自动发现已覆盖）。

### D2 ★ 阶段三的前置证据 = 0
阶段三第一项是「多团队并行 + 配额」。但实测**所有生产 runs 的 workspace_id 都是 `default`**（8/8），
唯一的非 default（`w2T`）来自 2026-09-22 的单次演练 oracle 日志。
⇒ 阶段三虽在文档里「未开工」，但连**开工所需的证据形态**（两个真 workspace 的并发批次）都还没有过。

### D3 题库仍是自建
`acceptance_v1` 三个 kind 共 7 题，全部是仓内自建题（`totp-001` / `json-null` / `cli-flag-001` / `preflight-gap-001` / `retry-budget-001` / `release-notes` 等）；
「换成外部真题」是阶段四的既有前置项之一，未换。

### D4 L2 的三条验收口径从未量过
`ROOT_MAP.md` §2 明确写着 L2 验收口径三条「将来一起量」：①冷启动定位耗时/token 降 ≥50%；②地图过期可检测；③新人只读 map 就能接手。
⇒ L2 标 ✅ 的是**功能可用**，不是**验收达标**；这条差值应计入「没做」。

### D5 门禁绿 ≠ 干净 clone 绿
阶段门 22 步里有条目依赖本地运行态（`runs/` 被 gitignore）；`derive_guard` 的仓外依赖已被
`FUTURE_CAPABILITIES.md` §15 显式承认为「干净 clone 里开箱即绿是假的」。
⇒ 本次复跑的意义是「本机当前状态无回归」，不等于「可复现交付」。

### D6 另一池库存（不属 herdr 架构，但属「还没做的事」）

其中 14 条已备好一句话批准语（`tools/pending_evidence.py` 输出）。这是**授权侧**的积压，不是设计或代码缺口。
