## 3. 修掉的真缺陷(5 处)
1. **git 窗口判定月粒度(会静默改数)**: `tools/git_contrib_stats.py:271-274` 把提交日期截成 `%Y-%m` 再与完整时间戳比较 => 窗边提交误判(评审实测「窗外误判 415」形态)。现改为「since/until 与提交日期双方都截到月」,并新增 `window_precision`(`exact`=月对齐 / `coarse`=非月对齐且**不再假报窗外**);月对齐窗下「author 出窗、committer 在窗」的提交(rebase 典型)**不再漏检**——A/B 夹具实证 HEAD 版 0/1 两向皆错。证据: `temp/review_ds_20261009/{FIX_LEDGER.md,git_smoke.json}`。
2. **失败静默**: 同文件 `:369` 原为 `return 0 if not errors else 0` => rc 恒 0;坏仓 / `git log` 失败时静默成功,把不完整数据当完整。现 `exit_code=3` fail-loud(负控已实测)。
3. **飞书分块丢页**: 分块路径每块只取 1 页(缺 `--page-all`)且缺 `has_more` 回退 => fail-open;两处同批修(自测 57/57,真实 API A/B 坐实)。
4. **禅道任务面分页未捕获**: my-work 无 pager 捕获 => 静默少数(与旧记「Bug 32=服务端单页上限截断」同源);现捕获分页并输出 `my_work_completeness` 告警。
5. **`quarter_window.py` 拒收 SOP 规定写法**: `2026-07-01T00:00:00+08:00`(RULES#9 要求)旧版 rc=2「无法解析日期」=> 照文档抄的命令跑不通;现接受(自测 30 checks)。
