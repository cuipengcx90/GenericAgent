# R568 L站浏览守护 try_ensure_tab 空转缺陷修复

日期:2026-10-10 | 类型:缺陷修复 | 对象:`tools/linuxdo_browse_daemon.py`

## 1. 现象

用户报「没有拉起吗 帖子一直没浏览」。核查:浏览器里只有 `connect.linux.do` 标签,
主站(`linux.do`)标签不存在;`try_ensure_tab` 当日 6 次自愈额度已耗尽,且 `ensure_tab.jsonl`
行 3–8 全部 `ok=true note=URLS:https://connect.linux.do/` —— 即「以为补了标签」实则空转。

## 2. 根因(同一语义两份判据)

`try_ensure_tab` 的 AppleScript EXISTS 判据用**子串** `contains "linux.do"`,被同族子域
`connect.linux.do` 骗过 ⇒ 命中「已有主站标签」分支,直接 `return "URLS:"` 早退、跳过建标签;
Python 侧又把这条 `URLS:` 回执一律当成功(`ok=True`)⇒ 额度被记成已使用,实际主站标签从未补上。
与 R557 属同一类缺陷(消费侧 `pick_session` 用精确 host,自愈侧用子串,两边矛盾)。

## 3. 修法(三处)

1. AppleScript 收集标签时**置位精确 host 门控** `_main`(`//linux.do/`、`//www.linux.do/`
   及尾部形式的 URL),仅当 `_main` 非空才 `return "URLS:"`;否则走新建标签分支。
2. Python 侧 `URLS:` 分支**fail-closed**:回执里不含主站 ⇒ 返回 `(False, "未新建主站标签(...)")`,
   不再计成功、不再消耗额度记账为成功。
3. `CREATED:` 分支解析新建结果,保留原有「建完切回原活动标签」行为(新标签留后台)。
