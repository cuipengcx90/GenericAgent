## 技术备注

| DB | 特殊限制 |
|----|---------|
| filecache.db file_meta | 需要自定义collation `baidunetdisksort` |
| filecache.db full_text_search | 需要自定义tokenizer `mars` |
| 有道云 content DB | 需要自定义tokenizer `simple` |
| Timing2 | ✅ 完全可读，无自定义扩展 |
| cloudpic.db | ✅ 完全可读，无自定义扩展 |
