## 4. 修法：fail-closed 参数闸门

`haisou_daily.py` 新增 `_argv_error(argv)`：已知参数仅 `--max-tasks N`（带值）与 `--selftest`（无值）；**任何未知 token ⇒ rc=2，打印用法后立即退出**，绝不进入真跑。

负控（当场实测）：

- `python3 birdie_monitor/haisou_daily.py selftest` ⇒ **rc=2**，stderr 首行 `[fail-closed] 未知参数 'selftest'（未知 token 会被当成真跑消耗站点配额，已拒绝）；用法: haisou_daily.py [--max-tasks N] | 自测: --selftest`
- 正控 `--selftest` ⇒ **rc=0**（53/53）

该负控已固化为自测用例 **T13**（`haisou_daily.py --selftest` 计数 52→53）。
