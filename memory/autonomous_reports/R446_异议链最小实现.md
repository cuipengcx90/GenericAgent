命令行面（纯 stdlib，`list`/`report`/`gate` **零写入**，只有四个写命令 append 一行 JSON）：

```
objection.py submit     --by WHO --target REV --severity S --evidence E --expires-at ISO [--id ID]
```

`gate --revision REV` 的拦停理由对外只给四个名字：`OPEN_OBJECTION` / `OBJECTION_CARRIED` /

## 3. 口径纪律（与 `skip_ledger_v0` 同一套）

1. **失败不落盘**：任何被判非法的操作都不许往台账写哪怕一行（写盘前先校验）。
2. **读命令零写入**：`list` / `report` / `gate`（含被拦停时）都不写盘。
3. **台账是唯一事实源**：坏行 / 非法转移序列 / 未知 id / 重号 id，读路径一律判 `LEDGER_INVALID` rc=1，不猜、不修、不跳过。
4. **过期不是通过**：`expires_at` 已过而仍 `SUBMITTED` 的异议**照样拦**，必须显式处置（`expire --disposition lapse` 才放行；`carry` = 明知过期仍继续追，继续拦）。
