## 1. 结论（先给答案）

1. **没有需要等待的「稳定期」。** 24 个可评估日里 **23 日**三个快照时点的前台时长**完全相同**（最大相对差 0.000%）；唯一非零日 2026-09-01 的 36.18% 差值由「窗口最老日的头部按 ts 剔除」完全解释（kind = EVICTION_HEAD），**无一天**发生回填或改写（`changing_days_real = []`，`verdict = EVICTION_ONLY`）。
2. **观测到的窗口形态**：kc `/app/usage` ≈ **24 天滚动窗口**（`max_age_days = 23.95`），且窗口最老日是被**逐行按时间戳剔除**、不是整日删除。2026-09-01 在 09-22 快照有 666 行原始行，到 09-25 快照剩 415 行；被剔除的 251 行**全部早于切割点**（`removed_after_cut = 0`）。
3. **消费侧口径建议（待批，§7）**：不要把「稳定期」当等待项，改为「**固定快照时点 + 丢弃窗口最老 1 天**」。这落实了 R426/R434 已声明的「熄屏/时长量必绑快照时点」，并首次给出可引用的形态依据。
4. **订正旧记忆**：L1 所记「同日 09-22 随快照 0.90 → 5.84 → 11.78h」**不可复现**。三次实测 = **0.844 / 7.600 / 7.600 h**，且 0.844 → 7.600 属**截断面**（快照落在当日内，只取到该日最终值的 11.1%），与回填无关。旧「铁证」应改写为「截断效应」。
5. **边界（必读）**：本结论只覆盖 2026-09-22 10:49:15 / 09-23 01:20:49 / 09-25 22:45:57 三个时点之间的可见变化；「T+k 天后变化 < x%」式的外推**证据不足**（§6）。

## 3. 方法与判据

- 工具 `tools/kc_backfill_stability.py`：三子命令 `points` / `matrix` / `stability`，纯 stdlib、只读；解析三份快照的 kc `/app/usage`（复用 `tools/kc_app_usage.py` 解析内核；导入失败显式报错，不静默降级）。
- 观测单位 = **日**（本地时区）：该日 `/app/usage` 全部行的前台时长求和 `fg`（小时）；另有 `dark`（`/display/isBacklit` v=0 熄屏量）与 `notif`（`/notification/usage` 条数）作旁证。
- 判定：同一日在不同快照间的 `fg` 相对差与容差 `tol_pct = 1.0%` 比较，并按证据分类：

| kind | 含义 | 判据要点 |
| --- | --- | --- |
| BACKFILL | 晚快照比早快照**多**出量 | fg 增加超容差 |
| REWRITE | 量级相近但内容被改写 | 行集合变化且无按龄剔除证据 |
| EVICTION_HEAD | 减少可由「最老日头部按 ts 剔除」完全解释 | 保留行起点 ≈ 切割点（秒级）∧ 晚于切割点仍被删 = 0 ∧ 被删时长与 Δfg 一致 |
| SHRINK_UNEXPLAINED | 减少但不能归因按龄剔除 | 上条不成立 |
| MISSING_DAY | 晚快照中**整日消失** | 早快照有数据 ∧ 该日 ≥ 该快照窗口头（防伪阳性） |

- `verdict`：`STABLE` / `EVICTION_ONLY`（仅按龄剔除，不计真变化）/ `CHANGING_REAL`（有真变化，`--strict` 时 rc = 1）/ `INTEGRITY_FAIL`（副本校验不过，rc = 2）。
- 旁路闸门：`dark` 按日求和与 `profile.py` 口径对账，闸门 0.05h（本次三快照分别 -0.0003 / 0.0004 / -0.0004 h，全部通过）。

## 6. 边界与残余风险

1. **时点是 3 个、不是一条曲线。** 快照只有 09-22 / 09-23 / 09-25 三份，两两间隔 0.61d / 2.72d，`max_age_days = 23.95`。能回答的是「在这三个时点之间，除窗口头剔除外没有可见变化」，不能回答「第 1 天到第 k 天的连续衰减曲线」。
2. **无法外推到 09-22 之前。** 窗口外的历史无从观测；若更早曾发生写回填，本工具看不到（它只做时点间比较）。
3. **8 个无效日不参与判定**（`usable_obs < 2`），其中 09-23 ~ 09-25 属评估面边界；不影响 24 个可评估日的结论。
4. **09-01 → 09-22 之间无采样（14 天）**，故「某日被回填后又趋稳」这类中途形态不可见。
5. **不构造跨源比值。** 本报告不引用、不比较 pmset / R426 的睡眠数据；kc 任何度量只按其所属快照时点引用。
6. **将来若出现真回填**：`--strict` 会把 `CHANGING_REAL` 变成 rc = 1，可直接用于定时巡检接线（§7 D2）。
