## 1 四处修复（全部落盘 + 自测绿 + 已上线）

1) **daemon 风控批内熔断**（tools/linuxdo_browse_daemon.py 124928B/2469 行，numstat 103+/4−）：`fetch_verdict()` 纯函数判「所有采样页失败 ∧ 强风控信号/封禁文案」⇒ ABORT；`browse_batch` 抛 `RiskAbort`（browse_log 落 `ABORT why=risk_abort:<kind>`，零帖）⇒ 主循环走 handle_risk。部分页失败仍有候选 ⇒ 只 NOTE 留痕。诊断留响应正文前 200 字。selftest **36/36**。

3) **定时任务步骤3 去重复私信**（sche_tasks/linuxdo_trust_level_check.json 2531B/7 行，1+/1−）：步骤 3 原在拉起后飞书私信提醒 ⇒ 与步骤 0 看门狗告警（已 6h 冷却）对同一事实双推。改后步骤 3 **不推送**、只留日志；需要人知道的仍由步骤 0 单点负责。trust_level_sop 补「通知单一源」条目。
