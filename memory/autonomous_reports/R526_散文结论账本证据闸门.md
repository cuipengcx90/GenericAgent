## 4. 判据口径（四条铁律 + 唯一分级）

1. **只报缺证据，不裁决正确性**：输出里不存在「证据对不对 / 结论成立不成立」这类字段。
2. **不许拿相邻行凑证据**：证据 token 必须与结论句**同行**（表格行算一行 ⇒ 探针列同格也可），
   躲开「证据在上一段、结论在本段」这种只能人判的软链接。
3. **语料空 = fail-closed（rc=2）**：目标文件全不存在，或抽出来 0 条结论句，都说明抽取口径或文件清单错位，
   **绝不当通过**。
4. **首跑只出差距清单**：历史文档不要求立刻补证据 ⇒ 缺口进 `--baseline` 冻结登记；
   冻结的是**句子内容哈希**（不是行号）⇒ 文档增删行不会把老缺口刷成新缺口，此后 CI 只拦**新增**的无证据结论。

唯一分级（铁律：**先判 ASSERT 再判 CRITERION**）：

| 分级 | 触发 | 缺证据时 |
| --- | --- | --- |
| `ASSERT` | 「已(闭环/落地/完成/通过/接线/实测/跑通)」「rc=\d」「MET」「✅」等**已发生**标记 | 计缺口 |
| `CRITERION` | 「必须/应当/门槛/判据/验收标准/负控/计划/目标/待办」等**应当**语 | 只入 `criteria_skipped`，不计缺口 |

ROADMAP 的验收条目/计划表因此不再刷屏，而「本机实跑 = 12 步 PASS」这类**宣称已跑**的句子仍会被点名。

CLI（位置子命令，非 `--flag`）：

```
python3 tools/prose_evidence_gate.py scan   [--only id,id] [--json OUT] [--limit N]
python3 tools/prose_evidence_gate.py check  …（CI 用，判据=退出码）
python3 tools/prose_evidence_gate.py baseline [--write]     # 默认 dry-run
python3 tools/prose_evidence_gate.py boundary               # 与 R410 / F15 的边界对账
python3 tools/prose_evidence_gate.py proof                  # 只读自证（跑前跑后 sha256）
python3 tools/prose_evidence_gate.py selftest               # 负控自测
```

退出码：`0` 无**新增**缺口／`1` 有新增缺口（未登记结论句）／`2` 语料为空或结论句 0 条（fail-closed）。
