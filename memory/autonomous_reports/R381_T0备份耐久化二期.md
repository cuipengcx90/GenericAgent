## §1 交付物与设计约束

**`tools/t0_snapshot.py`**（490 行，只用标准库：`argparse/hashlib/json/os/shutil/subprocess/tarfile/tempfile/time/pathlib`）

| 子命令 | 作用 |
|---|---|
| `list [--temp-scan]` | 列 T0 集合（文件数/体积/最大 8 项）+ `temp/` 顶层「哪些必须离开」清单（体积/文件数/7 天改动/git 状态/启发式判读） |
| `build [--only P] [--out D] [--tag T] [--encrypt] [--keep-plain]` | 生成 `ga-t0-<tag>-<stamp>.tar.gz` + `.manifest.json`（逐文件 sha256+size）+ `.SHA256SUMS`；`--encrypt` 走 openssl，**默认删除明文** |
| `verify <归档> [--encrypt] [--negctl]` | 解档到沙箱，逐文件 sha256 + 计数与清单比对；`--negctl` 故意篡改副本验证校验器真会报错 |
| `drill [--only P] [--out D] [--tag T] [--negctl]` | 端到端真演练：build → 解档核对 → **删掉副本** → 重新解档 → 再核对 → 负控 → 打印结论表 |
| `rotate [--out D] [--keep N]` | 保留最近 N 个**归档单元**（单元 = 基准名 + 其 `.enc/.manifest.json/.SHA256SUMS`，同进退），并清理无主清单 |

**关键设计决策（都是本轮踩出来的，见 §9）**

- **只读源数据**：所有子命令都不写被归档的文件；删/改只发生在沙箱（`$TMPDIR/t0_snapshot_work`）。演练结束时沙箱被清理（输出自证：`[drill] 沙箱 …/t0_snapshot_work 已清理`）。
- **判据是逐文件 sha256 + 计数**，不是体积：归档能否还原、还原得对不对，用清单机械比对。
- **归档自证哈希**：`build` 时把归档自身 sha256 写进清单（`archive_sha256`）——加密归档删掉明文后，仍有一个可核对的归档级指纹。
- **加密默认不留明文**：避免"加密了但明文还躺旁边"这种假安全。
- **T0 集合最小化**：只收「丢了就没了」的目录；`sche_tasks` 只收定义文件（`*.json/*.py`），不收产物。

## §9 已知限制与风险（含本会话修掉的工具缺陷）

**本会话修掉的 3 处真缺陷（都留了复现路径）**

1. **`rotate` 原本只按明文 `ga-t0-*.tar.gz` 计数** ⇒ 加密归档（只有 `.tar.gz.enc`）**不计入保留数**，`--keep 1` 时"保留 1 份"对加密件等于不设限。已改为**按归档单元**（基准名 + `.enc/.manifest.json/.SHA256SUMS` 同组）计数与删除；沙箱实测 3 单元 → `--keep 2` 只删最老的整组、`--keep 0` 删净、不留孤儿清单。
2. **孤儿清单判据会误删合法加密归档的清单**：加密归档的明文被删后，其 `.manifest.json` 会被当成"孤儿"。已修：仅当**基准名与 `.enc` 都不存在**才算孤儿。
3. **`list` 的 TOCTOU 崩溃**：`temp/` 里瞬时文件（其它会话/定时任务正在写）在 `stat` 前消失会让枚举崩溃。已加容错；复跑通过。

**其余限制**

- **归档目录本身在 `temp/`（gitignored）** ⇒ 同机同盘，只是"回到过去某个时点"，不是灾备。真实抗毁需 §7-1。
- **同盘写归档会占用空间**：全量单元 128 MiB（含明文 118,601,510 B）。数据卷当前 **13 GiB 可用 / 97% 占用** ⇒ 频繁全量快照会更快撞墙，建议先解决 §7-1/7-4 的空间问题。
- **tar + gzip 不是去重存储**：每次全量都是完整副本；`rotate` 只做保留份数，不做增量/去重（本轮刻意不引入增量格式，避免"依赖某工具才能读"的可读性风险）。
- **`--negctl` 是"抽样负控"**：只篡改排序后的第一个文件一字节，证明校验器会报错；不构成对全部文件独立篡改的覆盖证明。
- **未做跨设备恢复演练**：本轮解档都在本机 `$TMPDIR`。真正换机恢复需 §7-1 目的地确定后补做。
- **`sche_tasks` 只收定义文件**（`*.json/*.py`），不含任务产物；`logs/` 不含（R359 的日志回收另案、待批）。
- **环境相关**：本机 `sh` 会把命令串里的尖括号当重定向/glob —— 写"占位符式命令"时别用 `<>`（本轮踩过：`T0_PASSPHRASE=<random> …` 被 sh 解析成重定向报 `random: No such file or directory`）。已验收的所有命令都是不带尖括号的真实命令。
